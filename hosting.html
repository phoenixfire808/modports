Your server.
Your connection.

RustPorts is a discovery directory. It is not a game host, download service, proxy, tunnel, or relay.

For creators

  1. Use a public GitHub repository with clear setup instructions, an appropriate license, and an explanation of the rights to your original code and assets. Only submit projects you created or are authorized to represent.
  2. Choose and operate your own hosting, whether a dedicated server, cloud VM, or another provider. Follow your game's server documentation. RustPorts does not provision hosting or configure firewalls for you.
  3. Configure only the required game ports, updates, access controls, backups, and moderation. Use a public address intended for players. Hosting at home can reveal your home IP. Consider a dedicated hosting provider instead.
  4. Test from an external network yourself. A hostname and port alone do not bypass NAT or a firewall. If your network uses carrier-grade NAT, arrange suitable hosting or connectivity with your provider, not a RustPorts relay.
  5. Sign in, submit the project metadata, and optionally enter an address such as play.example.net:27015 or [2001:db8::1]:27015. These are examples, not working servers. Do not include a URL scheme, password, invite token, or private address.
  6. Track the review in My dashboard. Updating a published project's details or server address returns the listing to review. You can withdraw the listing when your server closes.

For players

  1. Open a project's public GitHub page and review its documentation, supported client, license, and security warnings. RustPorts does not distribute or verify game executables.
  2. Follow the creator's instructions to obtain and run the appropriate client. Only use software and assets you are legally entitled to use.
  3. If a server address is listed, use Copy address, then paste it into the game's own connection interface. Your client connects directly to the creator's server. RustPorts does not receive that game traffic.

Troubleshooting

If a connection fails, check the required client version and contact the creator through the repository. Addresses can change and servers can be offline. RustPorts does not check server availability. Report misleading or unsafe listings through our reporting process.

Rights and responsibility

Self-hosting does not make an infringing project lawful or remove anyone's legal responsibilities. Reimplementing in Rust or calling a project a parody does not automatically give permission to copy protected material. See the Terms and obtain appropriate legal advice for your project.
