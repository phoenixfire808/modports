Start with the spreadsheet method

Record observations and uncertainties, model supported facts with stable IDs, generate a validated matrix, then test the real implementation. The spreadsheet organizes your research. It does not automatically reconstruct a game or prove behavioral parity.

What you can try today

The Python starter includes an original example XLSX workbook, ID/reference validation, deterministic JSON generation, drift checks and tests. The native Jcode source is published separately for review and contribution. It has known issues and should not replace your installed Jcode.

Research responsibly

Use software you created, appropriately licensed examples, or work you are authorized to analyze. Do not upload proprietary game binaries, assets, private captures or credentials. Reimplementation and self-hosting do not automatically remove legal responsibilities. The guides are technical resources, not legal clearance.

Contribute

Report reproducible problems with minimal original examples through GitHub issues. Clearly separate observed results from hypotheses. Never post secrets or copyrighted game files. Read the toolkit's license and upstream notices before reuse.
